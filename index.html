About this site

lucifear is the name of my personal server, which I use to run and test the software projects listed below: game modding tools, reverse-engineering work, small web services and automation I build in my spare time. This page is the public homepage for that server and an index of the projects hosted on it. Everything here is a personal, non-commercial hobby project.

Projects

KuroPatch

Android patching tooling for game translation and modding workflows — patch creation, application and verification, built with Kotlin and Gradle.

KuroGBA

A Game Boy Advance emulator build for Android based on mGBA, packaged as a lightweight offline APK with no internet permission.

secret-sniffer

A small security utility that scans projects for accidentally committed secrets and credentials before they are published.

Harvest Moon: Back to Nature — recompiled port (in progress)

Static recompilation research on the PlayStation 1 game: decompilation matching, overlay analysis, and a native PC/Android port built on top of a byte-identical vanilla rebuild of the original disc.

Personal knowledge base & automation

A searchable local knowledge base of my security-research notes, plus small automation agents that help with recon triage, documentation and day-to-day development tasks on the lucifear server.
